Частые вопросы

Как найти расширение для моей модели телевизора?

Открой страницу платформы выше. Если модель телевизора или версия системы не указана в карточке, совместимость с ней пока не подтверждена.

Можно ли доверять любому плагину из каталога?

Нет. Каталог показывает источник, но не гарантирует безопасность чужого кода. Устанавливай только расширения, автору которых доверяешь, и не вводи секреты в непроверенные плагины.

Почему нет отметки «работает»?

Потому что для неё нужен конкретный тест. Ответ сайта по ссылке сам по себе не доказывает, что расширение загрузится в Lampa на Samsung, LG или Android TV.
