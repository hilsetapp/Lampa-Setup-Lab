# Lampa Setup Lab

Подборка расширений Lampa по устройству и задаче. У каждой карточки указан источник сведений и уровень проверки. Каталог не выдаёт слова автора за независимый тест.

## Что уже есть

- Каталог на 33 расширения с поиском по названию и назначению.
- Фильтры по устройству, категории и уровню проверки.
- Отдельные страницы для Samsung Tizen, LG webOS и Android TV.
- Инструкция по добавлению расширения.
- Понятная шкала проверки: заявлено автором, ссылка проверена, запущено в Lampa, проверено на устройстве.
- Скрипт проверки каталога и дублей URL.

## Как открыть

Самый простой способ - после шага сборки данных открыть `docs/index.html` двойным щелчком. Поиск и фильтры работают без сервера.

После изменения `docs/data/plugins.json` пересобери локальные данные сайта:

```bash
python scripts/build_catalog_data.py
```

Для локального сайта с переходами между страницами:

### Windows

1. Установи Python 3 с сайта python.org. При установке отметь **Add Python to PATH**.
2. Открой папку `docs` в Проводнике.
3. Нажми на адресную строку, введи `cmd` и нажми Enter.
4. В появившемся окне введи:

   ```text
   py -m http.server 8000
   ```

5. Открой в браузере `http://localhost:8000`.
6. Чтобы остановить сайт, вернись в чёрное окно и нажми `Ctrl+C`.

### macOS или Linux

Открой терминал в папке `docs` и выполни:

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Проверка каталога

Нужен Python 3. Запусти из корня репозитория:

```bash
python scripts/validate_catalog.py
```

Скрипт проверяет структуру JSON, обязательные поля, повторяющиеся ID и URL, а также корректность уровней проверки. Он не ходит по внешним адресам и не подтверждает, что расширение работает на телевизоре.

## Важное про статусы

- **Заявлено автором** - функция и совместимость описаны в источнике проекта.
- **Ссылка проверена** - URL расширения ответил на сетевой запрос в указанную дату.
- **Запущено в Lampa** - тест подтвердил загрузку расширения в Lampa.
- **Проверено на устройстве** - тест пройден на конкретной модели и версии системы.

На 27.10.2026 прямые ссылки всех 33 карточек и скрипты, которые загружают плагины LampaME, ответили HTTP 200. JavaScript-файлы прошли проверку синтаксиса. Это подтверждает доступность и корректность синтаксиса, но не работу внутри Lampa. Плагины не запускались в приложении Setup Lab и не проверялись на телевизорах. Поэтому статус каждой карточки точно описывает имеющиеся доказательства, а не обещает, что плагин заработает на любом устройстве.

## Как предложить расширение или тест

Создай issue с названием расширения, ссылкой на страницу автора, прямой ссылкой установки и устройством, на котором его проверяли. Для результатов теста приложи версию Lampa, модель устройства и короткое описание действий. Не присылай токены, пароли и личные данные.
